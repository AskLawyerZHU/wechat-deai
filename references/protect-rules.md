# 不可动清单（通用）

## 为什么单列一份

去 AI 味的动作里，有一半会诱导改写者"顺手改得更生动"。这一步就是事故现场。

一句话原则：**风格可以改，事实一个字都不动。改不动的地方，就是文章的地基。**

本文件适用于所有行业。法律、医疗、金融等强监管行业另加 `legal-guard.md`。

---

## 一 绝对不可动

| 类别 | 具体内容 | 违规后果 |
|---|---|---|
| 数字 | 金额、比例、数量、时长、日期 | 事实错误 |
| 编号 | 条款号、标准号、型号、版本号、条文序号 | 无法核实，等于伪造 |
| 专有名词 | 机构全称、产品名、地名、项目名 | 张冠李戴 |
| 引语 | 当事人原话、访谈原话、文件原文 | 篡改他人陈述 |
| 可识别身份 | 姓名、职务、任职关系 | 侵权与失实 |
| 时间节点 | 发布日、生效日、截止日、起算点 | 影响结论 |
| 流程状态 | 阶段名、环节名、审批状态 | 性质错误 |
| 作者判断 | 作者已明确表达的立场、倾向、取舍 | 替作者表态 |

---

## 二 确定性不可被强化

改写时最隐蔽的错误，是把不确定写成确定。改完读起来更有力，但性质变了。

| 原文 | 禁止改成 |
|---|---|
| 可能构成违约 | 构成违约 |
| 据了解、据称、听说 | 事实证明、经查实 |
| 尚未生效、尚未上线 | 已经生效、已经上线 |
| 拟、计划、筹备 | 决定、承诺、已经 |
| 初步判断、初步测算 | 认定、确认 |
| 有观点认为 | 普遍认为 |
| 部分机构、个别案例 | 行业普遍、多数案例 |
| 存在争议、尚无定论 | 已有定论、业界共识 |
| 一般应当 | 必须 |
| 倾向于 | 一定会 |
| 约、左右、上下 | 精确到个位（除非原文如此） |

反向也禁止：不能把确定的写成模糊来"显得专业"。原文说"判决支持"，不能改成"法院似乎倾向于支持某方"。

---

## 三 数字与单位

- **统一写法**：同一篇文章里"3.5 万元"和"35000 元"不能并存。
- **比例**：写"30%"或"三成"，不要把"30 个百分点"当"30%"用。
- **期限**：写明单位。不同单位的期限在生活中可换算，在规则里可能不同，不要互相折算。
- **不可约数化**：原文"五份合同"不能改成"几份合同"；"三次"不能改成"多次"。
- **没有数据时**：写"没有公开数据"，或删掉程度词。**不写"大幅""显著""绝大多数"。**
- **对照组**：原文有对比基数时，不能只留一半。删掉基数会让比例失真。

---

## 四 引用与归因

- 有实名出处的，保留出处和它的主张范围，不能扩大。
- 只有"有专家认为""业内普遍认为"这类笼统归因时：保留其局限，或整句删掉。**不得替换成一个具体但虚构的机构、报告、年份。**
- 原文引用加引号，保留原字句，包括原文的病句和标点习惯。不要"帮它改通顺"。
- 转述与引用要分清：转述不加引号，引用必须加。
- 二次引用要标明是转引。转引不能写成"我看到原始研究显示"。

---

## 五 脱敏（通用）

用户要求脱敏时：

| 对象 | 处理 |
|---|---|
| 自然人 | 姓＋某，如"张某""李某"；同一人全篇一致 |
| 组织 | "甲公司""乙公司"；需要区分关系时用"甲公司的子公司" |
| 金额 | 保留量级或改为区间，但不得改变后果的性质（是否跨过某个门槛） |
| 地址 | 保留到市，不写具体门牌 |
| 时间 | 保留年月，日可模糊 |
| 编号 | 保留可公开的部分，序号可用"XX" |

脱敏后检查一遍：把两处信息拼起来还能不能认出当事人。能认出的，再模糊一层。

---

## 六 不允许的"生动化"

以下改写看着像在去 AI 味，实际在制造错误：

| 动作 | 问题 |
|---|---|
| 给抽象判断配一个编造的案例 | 伪造事实 |
| 把"我处理过很多"加进去 | 伪造履历 |
| 把原文改写成更口语的版本并加引号 | 篡改原文 |
| 给"损失巨大"填一个具体金额 | 伪造数据 |
| 把当事人的话改得更符合逻辑 | 篡改陈述 |
| 补充"实践中通常"作为论据 | 无据归因 |
| 把"一审"改成"法院"这类层级简化 | 混淆阶段 |

---

## 七 该问用户而不是自己决定的四种情况

1. 原文出现具体数字但没写来源 → 问出处，不猜。
2. 原文提到案例但要素不全 → 问时间、行业、结果，问不到就删。
3. 原文有作者的判断但语气含糊 → 问作者到底怎么想，不替作者表态。
4. 原文涉及未公开信息 → 问能否公开、脱敏到什么程度。

一次不超过三个问题，且要问得可回答。"能说点细节吗"无效；"这个案子是哪一年结的"有效。

---

## 八 交付前最后一遍

- 逐条核对：所有数字、编号、专有名词、时间节点与原文完全一致。
- 逐句核对：所有"可能／尚未／据了解／拟／约"是否原样保留。
- 清点新增内容：这一稿里有多少信息是原文没有的？每一处都要能指出来源。指不出来，撤回。
