# 法律内容专项

## 适用条件

仅当文章内容是法律、司法、合规相关时读本文件。其他行业不需要，通用规则已在 `protect-rules.md`。

法律内容的特殊风险：**大部分口语里像同义词的词，在法律上是不同的事。** 去 AI 味的过程会诱导把术语换成大白话，这一步在法律内容上直接构成错误。

---

## 一 术语不可互换

任何一个都不能为了"读起来顺"而替换。

| 术语 | 不能换成 |
|---|---|
| 判决 | 裁定、决定 |
| 裁定 | 判决、决定 |
| 决定 | 判决、裁定 |
| 返还 | 赔偿、补偿 |
| 赔偿 | 补偿、返还 |
| 补偿 | 赔偿、返还 |
| 合同无效 | 合同可撤销、合同不成立 |
| 可撤销 | 无效、效力待定 |
| 效力待定 | 无效、可撤销 |
| 解除 | 撤销、终止、撤回 |
| 撤销 | 解除、撤回 |
| 终止 | 解除 |
| 定金 | 订金、押金、保证金 |
| 订金 | 定金、押金 |
| 连带责任 | 按份责任、补充责任 |
| 按份责任 | 连带责任 |
| 补充责任 | 连带责任 |
| 诉讼时效 | 除斥期间、追诉期 |
| 除斥期间 | 诉讼时效 |
| 起诉 | 上诉、申请再审、申诉、立案 |
| 上诉 | 起诉、申请再审 |
| 申请再审 | 上诉、申诉 |
| 认缴 | 实缴 |
| 实缴 | 认缴 |
| 代持 | 转让、信托、托管 |
| 无权代理 | 表见代理 |
| 表见代理 | 无权代理 |
| 缔约过失 | 违约责任、侵权责任 |
| 违约责任 | 侵权责任、缔约过失 |
| 侵权责任 | 违约责任 |
| 执行 | 审理、立案 |
| 终本 | 结案、终结执行、执行完毕 |

补充：**"追诉期"不是法律术语**。刑事语境用"追诉时效"，民事语境用"诉讼时效"。出现即改。

## 二 程序与文书

| 项 | 规范 |
|---|---|
| 程序阶段 | 一审、二审、再审、执行、发回重审、终审——不得混用，不得简化成"法院" |
| 文书类型 | 判决书、裁定书、调解书、决定书——不同文书对应不同事项，不互换 |
| 案号 | 保留原始格式，含法院代字、年份、案件类型代字、序号，不简写不改写 |
| 法律名称 | 首次出现写全称《中华人民共和国民法典》，后文可简称《民法典》；不用"民法"泛指 |
| 条文引用 | 写"《民法典》第五百七十七条"，不用"第577条"混排；同一篇统一一种写法 |
| 司法解释 | 写全称加文号；不要把司法解释当法律引用 |
| 当事人称谓 | 原告／被告／第三人／上诉人／被上诉人／申请人／被执行人——按程序阶段准确使用 |

## 三 排版格式

| 项 | 规范 |
|---|---|
| 金额 | 阿拉伯数字＋中文单位，如"3.5 万元"；全篇统一 |
| 日期 | 统一"2024 年 3 月 12 日"，不用"24年3月" |
| 期限 | 写明单位（日／月／年），不与"90 天"互相折算 |
| 脱敏 | 自然人"张某"、公司"甲公司"，全篇一致，不中途换称呼 |
| 法条原文 | 加引号，保留原字句与标点，不"帮它改通顺" |

法律内容的脱敏还要多一层检查：金额脱敏后，是否改变了法律后果的性质（是否跨过"数额较大""情节严重"的门槛）。跨了就宁可保留量级，也不改性质。

---

## 四 法律内容里最容易犯的五个改写错误

1. **把"判决"写成"裁定"**——为了让句子短一点。两种文书对应完全不同的事项。
2. **把"返还"写成"赔偿"**——"赔偿"暗示有过错，"返还"只是物归原主，责任基础不同。
3. **把"可撤销"写成"无效"**——无效是自始无效，可撤销是效力待定且需行使撤销权。程度差一个量级。
4. **把"终本"写成"结案"**——终本只是本次执行程序终结，债权仍在，可恢复执行。写成"结案"，读者会以为案子完了。
5. **把"一审"写成"法院"**——读者无法判断这个结论的效力层级，可能还没生效。

这五处全部属于"读起来更顺但性质变了"的类型，也是最难自查的类型。改完必须专门过一遍。

## 五 免责声明

法律科普类内容面向公众发布时，保留一句最短免责即可：

> 本文不构成对具体案件的法律意见。

不要写成一段。免责声明越长，越像在替内容质量打补丁。

## 六 交付前核对

- 上面的 32 条术语对照过一遍：有没有任何一个被换成了近义词？
- 程序阶段名是否原样？
- 案号、条文号、法律名称是否与原文完全一致？
- 脱敏后，金额是否仍能体现原本的法律后果性质？
- 免责声明是否压到一句？
