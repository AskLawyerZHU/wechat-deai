# 公众号手机屏节奏规范

## 物理前提

公众号在手机上读，正文常见 16px、行距 1.7。一屏大约 250–350 字。读者的手指随时准备上滑。

这条物理事实决定了三件事：段落必须碎，小标题必须密，前三行必须留住人。

## 段落

| 项 | 规范 |
|---|---|
| 常规段落 | 20–70 字，最多不超过 80 字 |
| 独立短段 | 5–15 字，单独成行，全篇 5–8 处 |
| 连续等长 | 禁止连续三段字数接近 |
| 一段一事 | 一个自然段只讲一件事，讲完就断 |

独立短段是公众号最有效的节奏工具。它承担三种功能：转折（"但问题在这。"）、结论（"这叫无权代理。"）、落点（"钱要不回来了。"）。用在读者会停顿的地方，不要用在随便哪一段后面。

## 小标题

- 每 350–600 字一个。
- 不超过 12 字。
- 用读者会自己问出来的句子，不用名词短语。

| 名词化（差） | 口语化（好） |
|---|---|
| 一、股权代持的法律风险 | 一、钱是你出的，名字不是你的 |
| 二、实务操作建议 | 二、真要打官司，先证明这三件事 |
| 三、结论 | 三、这份协议我劝你别签 |

例外：给客户看的意见书、白皮书、正式报告，名词化标题更专业。

## 开头三行

前三行决定划走率。三种可用公式，选一种，不要混用：

**A 具体场景**：时间或处境 ＋ 一个动作 ＋ 一个反常结果。
**B 反常识结论**：先给判断，后文证明。判断必须具体到读者能反驳。
**C 代价前置**：不做的后果，具体到钱、权、时间。

三种都不能用的场合（例如纯政策解读），就用最短的事实交代开头，不超过十五字，然后立刻进入具体条款。

## 结尾

三选一：

- **给下一步**：读者明天能做的具体动作。
- **给代价**：不做的后果，写具体。
- **自曝边界**：这件事我也没想清楚的地方，或什么条件下结论会变。

不要四选四。结尾只留一个落点。

## 标点

| 项 | 规范 |
|---|---|
| 全角半角 | 中文标点一律全角，禁止半角逗号句号 |
| 破折号 | 全篇不超过 2 处 |
| 感叹号 | 全篇不超过 2 处 |
| 引号 | 全篇统一，不混用「」和 "" |
| 省略号 | 用……，不用。。。 |
| 括号 | 中文内容用中文括号 |

## Markdown 语法

公众号编辑器不认 `##`、`**`、`- `。正文里出现这些符号，读者直接看到星号和井号，是最明显的机器痕迹。

- 小标题用编辑器的小标题样式，不手打 `##`。
- 强调用编辑器的加粗按钮，不手写 `**`。
- 列表用编辑器的列表，不手打 `-`。

## 加粗与 emoji

- 加粗：每屏不超过 1 处，只加在结论句或代价句上。整段加粗等于没有加粗。
- emoji：正文不用。小标题可用，全篇不超过 3 个，不放在句首堆叠。
- 分隔线：全篇不超过 2 处。

## 图片位

- 每 500–700 字一个图片位。
- 优先放信息型图片：判决书局部、条款截图、流程表、数据表。装饰图不如不放。
- 图注写在图片下方，一句话说明这张图在证明什么，不要写"图一"。

## 字数

| 类型 | 建议 |
|---|---|
| 法律科普 | 1800–2800 字 |
| 商业评论 | 1500–2500 字 |
| 案例复盘 | 2000–3000 字 |
| 短推文 | 600–900 字 |

低于 1200 字很难承载一个完整论证，高于 3500 字手机端完读率会明显下降。宁可砍，不要注水。

## 行业内容排版

强监管行业（法律、医疗、金融）的编号、术语、机构名有固定写法，不能为了节奏或口语化改动。具体规范见 `legal-guard.md`（法律部分）。

通用三条：

| 项 | 规范 |
|---|---|
| 数字 | 阿拉伯数字＋中文单位，全篇统一一种写法，不混用"3.5 万"和"35000 元" |
| 日期 | 统一"2024 年 3 月 12 日"，不用"24年3月" |
| 专有名词 | 首次出现写全称，后文可简称；同一篇里简称方式统一 |

## 与其他格式的转换

本文件的规范针对公众号正文。同一篇内容要发到其他平台时，段落长度、小标题样式、图片位密度都要重新调——手机屏宽度不同，一屏字数不同，直接复制过去节奏会散。
